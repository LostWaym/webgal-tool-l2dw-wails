# 编辑器主题规范

预览设置 → 外观是写入口。预览、模型、演出和动作编辑器共同使用用户配置目录 `L2DW/appearance` 中的主题 ID；不写入项目、模型或动作。缺失或过时的 ID 读取为默认主题。

## 新增主题

在 `frontend/src/themes/palettes.json` 添加一个主题；第一项是默认。ID 稳定且唯一，`scheme` 取 `light` 或 `dark`，颜色使用六位十六进制。注册表同时供前端和 Go 原生窗口读取；色卡随注册表生成。

可选 `profile` 用于套用全局控件轮廓与阴影（`tech`、`industrial`、`warm` 定义于 `frontend/src/style.css`）。不设时使用默认控件风格；轮廓不改变尺寸和点击区域。

| 色彩角色 | 用途 |
| --- | --- |
| `window` / `panel` / `well` | 窗口、面板和内嵌区域 |
| `control` / `hover` / `selected` | 控件底色、悬停和选中底色 |
| `line` / `edge` | 装饰分隔线 / 需要辨认的控件边界 |
| `text` / `muted` | 正文 / 辅助文字（包括占位符） |
| `accent` / `on-accent` / `link` | 实心主按钮与其文字 / 可交互文字及焦点指示 |
| `success` / `warning` / `danger` / `alternate` | 成功、警告、危险及第二类对象标记 |

- 界面 CSS 引用 `var(--ui-角色)`；蒙层、状态浅底等派生色由 `frontend/src/style.css` 定义。不要在组件中按主题 ID 写分支。主题挂在 `html`，Teleport 与弹出菜单继承同一套变量。
- 通用按钮、页签和弹窗优先复用 `ui-button`、`ui-tab`、`ui-dialog`；紧凑控件使用共享的小圆角，不为换肤改变点击区和时间轴几何。预览舞台的操作提示只让底板透出画面，不降低文字与快捷键的不透明度。
- Pixi 编辑辅助图形从 `themeColor()` 取色，通过重绘辅助层或更新 tint 同步；不重建舞台。取色器色域、用户背景、滤镜、导出底色等表示作品数据，保持原值。
- 正文、辅助文字及按钮文字在实际底色上的对比度至少 4.5:1；关键控件边缘、焦点和图形至少 3:1。重要状态同时使用描边、形状、图标或文字。使用半透明背景时还要在实际内容上检查。
- 切换不得丢失视口、选中对象、未保存的编辑或播放位置。验证所有窗口已打开、稍后打开、独立启动及重启四种情况。真实桌面进程的联动不能用同页组件测试代替。

`theme.go` 以同目录临时文件替换偏好并监听目录变化；每个进程通知自己的 WebView 重读。`frontend/src/themes/appearance.ts` 负责首屏应用、串行保存、落盘失败恢复和重新聚焦校准。

从项目根目录运行 `node frontend/scripts/check-themes.mjs` 可检查主题 ID、角色完整性和基础色板对比度；`go test ./...` 检查偏好持久化及错误处理。
